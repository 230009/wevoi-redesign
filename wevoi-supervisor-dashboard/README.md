# WeVoi Supervisor Dashboard

## Description
Supervisor dashboard plugin for WeVoi Competition Management system.

## Features
- Dashboard for supervisors
- Track student competition registrations
- View competition results
- Access supervisor certificates

## Installation
1. Upload the plugin files to the `/wp-content/plugins/wevoi-supervisor-dashboard` directory
2. Activate the plugin through the 'Plugins' screen in WordPress

## Usage
Use the shortcode `[supervisor_dashboard]` on any page to display the supervisor dashboard.

## Requirements
- WordPress 5.0+
- PHP 7.2+
